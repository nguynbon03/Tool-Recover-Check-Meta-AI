# Huong dan cai dat va chay FB Recovery Tool

## Yeu cau
- Windows 10/11 64-bit
- Google Chrome (version moi nhat)
- Python 3.11+ (tai tai https://python.org)

## Cai dat lan dau
1. Cai Python 3.11+, tick "Add Python to PATH"
2. Mo Command Prompt (cmd), chay:
   pip install -r requirements.txt

## Chay tool
Double-click file: RUN.bat

## VPS SSH Key
- Tai PuTTYgen tu https://putty.org
- Load file .ppk → Conversions → Export OpenSSH key → luu vao C:\Users\TEN_MAY\.ssh\vps_key_openssh

## VPS POOL format
Dien vao o VPS POOL:
178.128.113.1 root
(moi dong 1 VPS)

## Accounts format
Moi dong 1 email/phone
